📘 Help & Documentation

1. Select City and Date Range:

Choose a U.S. city and the time window you'd like to analyze. The system will retrieve historical demand and weather data for this period.

2. Cluster Count (k):

This determines how many distinct demand patterns the system will identify. Higher values may reveal more nuanced patterns but could overfit.

3. Forecasting Models:

Select which machine learning models to compare. The interactive forecast plot will show predictions alongside actual demand values.

4. Interactive Features:
  • Hover: View exact values by hovering over points
  • Zoom: Click and drag to zoom, double-click to reset
  • Toggle: Click legend items to show/hide clusters or models
  • Pan: Click and drag to move around the plot
5. Technical Details:

The system uses PCA to reduce high-dimensional demand/weather patterns to 2D for visualization. Forecasts are generated using scikit-learn models trained on historical data.
