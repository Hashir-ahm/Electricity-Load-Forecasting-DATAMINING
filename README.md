# Electricity Load Forecasting — Data Mining

Forecasting hourly electricity demand for major U.S. cities from weather data, plus clustering of demand–weather patterns, with a small Flask web app to explore the results.

> Data Mining course project, FAST NUCES Islamabad (May 2025) — Sami Ullah, Azhaff Khalid, Hashir Ahmed.

## What's inside

| File | Purpose |
|---|---|
| `python-notebook.ipynb` | Full pipeline: cleaning, feature engineering, anomaly detection, clustering, model training & comparison |
| `app.py` | Flask web app — pick a city, date range and models, get interactive Plotly charts |
| `forecast.py` | Trains Linear Regression / Random Forest on temperature, humidity and wind speed and returns predictions |
| `cluster.py` | Standardises features, reduces to 2D with PCA and clusters with K-Means |
| `templates/index.html` | Web app front end |
| `report.docx` | Project report |

## Approach

- **Data:** hourly electricity demand + weather for U.S. cities (Kaggle).
- **Preprocessing:** missing-value imputation, time features (hour, day of week, season), outlier detection with z-score and **Isolation Forest** (anomalies replaced with the city/hour median).
- **Clustering:** PCA, then **K-Means** (elbow method), **DBSCAN** and **hierarchical clustering**, compared with silhouette scores — e.g. "high demand, hot weather" vs "low demand, cool weather".
- **Forecasting:** Linear Regression, Random Forest (GridSearchCV), XGBoost, MLP and SARIMAX, compared against a naive baseline using MAE / RMSE / MAPE.

## Run the web app

```bash
pip install flask pandas numpy scikit-learn plotly
python app.py
```

Then open http://127.0.0.1:5000.

> The app reads `clustered_electricity_demand.csv`, which is generated by the notebook and is not committed (too large). Run the notebook first, or place the CSV in the project root.

Cities available in the app: Dallas, Houston, Los Angeles, New York, Philadelphia, Phoenix, Seattle.
